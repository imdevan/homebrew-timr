# Homebrew Tap for timr

This is the official Homebrew tap for [timr](https://devan.gg/timr).

The formula is named `timr` but installs the binary as `timr`.

## Installation

```bash
brew tap imdevan/timr
brew install timr
```

## Usage

After installation, use the `timr` command:

```bash
timr --help
```

## Updating

```bash
brew update
brew upgrade timr
```

## Uninstall

```bash
brew uninstall timr
brew untap imdevan/timr
```
